📱 GS25 노무시스템 앱 설치 가이드

1파일 호스팅 준비

이 폴더 전체를 웹서버에 올려야 합니다. 무료 방법:

  • ✅ GitHub Pages — 무료, 영구적 (권장)
  • ✅ Netlify Drop — netlify.com/drop 접속 후 폴더 드래그 앤 드롭
  • ✅ Vercel — GitHub 연동 무료 배포
⚠️ 로컬 파일(file://)로는 PWA 설치 불가. 반드시 https:// URL 필요

2Android 설치 방법 (갤럭시 폴드7)

  1. 크롬 브라우저로 배포된 URL 접속
  2. 우측 상단 메뉴(⋮) 탭
  3. "앱 설치" 또는 "홈 화면에 추가" 선택
  4. 설치 완료 — 앱 서랍에 GS25노무 아이콘 생성

3iOS 설치 방법 (아이폰/아이패드)

  1. Safari로 URL 접속 (크롬 불가, 반드시 Safari)
  2. 하단 공유 버튼(□↑) 탭
  3. "홈 화면에 추가" 선택
  4. 설치 완료

4PC(Windows) 설치 방법

  1. Chrome 또는 Edge로 URL 접속
  2. 주소창 우측 설치 아이콘(⊕) 클릭
  3. "설치" 클릭 — 독립 창 앱으로 실행됨

🔑 핵심 특징

  • ✅ 완전 오프라인 동작 — 인터넷 끊겨도 정상 작동
  • ✅ 데이터 보존 — 기기 localStorage에 영구 저장
  • ✅ 앱 아이콘 — 홈화면/앱 서랍에 GS25 전용 아이콘
  • ✅ 전체화면 — 브라우저 UI 없이 네이티브 앱처럼 실행
